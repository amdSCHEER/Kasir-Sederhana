# Tugas Kasir Sederhana - Git & GitHub

Proyek ini dibuat buat menuhin tugas praktikum tentang penggunaan Git dan GitHub. Di repo ini udah lengkap ada minimal 3 kali commit dan udah pakai fitur branch sama merge juga buat nyatuin kodenya.

## Fitur Program:
1. Bisa input harga barang sama jumlah beli terus keluar totalnya.
2. Ada sistem cek saldo buat nyari tahu kalau uang cash yang dibayar kurang.
3. Otomatis dapet potongan diskon 5000 kalau total belanjanya di atas 50 ribu.

## Riwayat Commit:
- Commit awal: Bikin struktur kode kasir yang paling dasar dulu.
- Commit kedua: Nambahin logika if-else buat ngecek kalau uangnya kurang.
- Commit ketiga: Ngerapihin baris kode biar nggak berantakan.
- Commit terakhir (Merge): Nyatuin fitur diskon dari branch sebelah ke branch main.

## Branching & Merging:
Kemarin sempat bikin branch terpisah namanya `Fitur-Diskon` khusus buat ngelasur fitur potongan harga biar nggak ngerusak kode utama. Sekarang fiturnya udah aman dan udah berhasil di-merge (digabungkan) lagi ke branch `main`.
